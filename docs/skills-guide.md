# Guia de Skill do Projeto

## O que e uma skill

Uma `skill` e um conjunto de instrucoes especializadas para orientar como o agente deve atuar em um contexto especifico.

Ela serve para:
- padronizar analise tecnica
- manter contexto de negocio
- reduzir respostas genericas
- acelerar manutencao, arquitetura e validacao

## Como ficou neste projeto

Neste repositorio, a skill operacional principal esta em [SKILL.md](/c:/Users/tsilv/Downloads/salon%20fun/SKILL.md).

Ela foi criada para o seu SaaS de:
- saloes de beleza
- barbearias
- estetica
- atendimento com agendamento

## Quando usar

Use essa skill quando o trabalho envolver:
- agenda do salao
- app cliente
- planos recorrentes
- feed e stories
- financeiro e operacao
- arquitetura SaaS
- bugs de producao
- validacao com dados reais

## O que essa skill orienta

Quando voce mandar tela, erro, modulo ou ideia, ela orienta o agente a:
1. entender o objetivo do modulo
2. avaliar a arquitetura atual
3. identificar problemas de UX, regra de negocio, performance e organizacao
4. sugerir melhoria profissional
5. gerar codigo funcional quando necessario
6. apontar exatamente os arquivos alterados
7. evitar quebrar o que ja existe
8. pensar como produto SaaS vendavel
9. validar com teste, build e, quando fizer sentido, producao real

## Observacao importante

No Windows, `skill.md` e `SKILL.md` sao tratados como o mesmo arquivo. Por isso a explicacao humana ficou neste guia e a skill real ficou consolidada em `SKILL.md`.
